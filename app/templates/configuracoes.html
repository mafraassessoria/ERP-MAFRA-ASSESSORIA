Configurações

E-mail de envio das notas (SMTP)

Gmail: servidor smtp.gmail.com, porta 587, STARTTLS. Como senha, use uma senha de app (Conta Google → Segurança → Verificação em duas etapas → Senhas de app), não a senha normal.

Importação pelo ADN

Para clientes que não entregam o certificado: cadastre o escritório como prestador (modo "somente importação"), envie o e-CNPJ do escritório e escolha-o aqui. Cada cliente precisa conceder procuração eletrônica ao escritório para a NFS-e.

Cópia dos XML para outra pasta

Cada XML de produção (emitido ou importado) também é copiado para pasta\CNPJ\, sem duplicar — útil para alimentar outro sistema (ex.: NF-Stock, escrita fiscal).

Serviços de obra (construção civil)

4 dígitos separados por vírgula (ex.: 0702 = subitem 7.02). Quando o código de tributação da nota começa com um destes subitens, a tela de emissão mostra o grupo Informações para obra e a redução da base de cálculo.

Cadastro geral de empresas

Importe o empresas.json do Bot Arquivador para trazer a pasta de cada empresa no Drive, os CNPJs adicionais e os outros nomes usados para reconhecer documentos. Empresas que ainda não existem aqui são criadas sem o módulo NFS-e. Nada é apagado e os dados fiscais das empresas existentes não mudam.

e-Contador e certidões

API ePlugin do e-Contador (somente leitura): liga as empresas pelo CNPJ e traz as certidões do Pack CND. As certidões novas são entregues na pasta de entrada do Bot Arquivador, que as guarda na pasta Certidões de cada empresa.
